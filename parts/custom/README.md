# 旧日来信 · 定制（纪念册）

「定制」tab 的相册制作流程，两条路：

- **导入**：书架 → 纸盘「导入」→ 信封滚轮选一个已建好的空间 → 直接「装订中」（自动导入空间里的图片，不含视频）→ 合上的相册。
- **创建**：书架 → 纸盘「创建」→ 选模板 → 上传照片 → 装订 → 合上的相册。

相册三层：**合上**（外观：封面 / 背景设置）→ 点书 **打开**（全部页面总览 + 缩略图条）→ 点左页 / 右页 **放大编辑那一页**。
装订时照片按顺序一页一张排进相册，照片多就自动加页（页数补成双数，左右页成对）。每一页各自存照片、贴纸、文字、背景色、描边、抠图状态。
做好的相册在书架上显示它自己的封面；点它，书从书架上拿下来放大到地板上（合上状态）。

**书架是多本相册的**：demo 默认打开是空书架（没有预置的一本），每次「创建/导入」都会新增一本独立的相册，互不覆盖；一层书架放 3 本，等距排开，放不下自动换行。

## 实现方式

- 每一屏 = 背景层（跟随背景设置）+ Figma 导出图（挖掉状态栏和所有画死的按钮/卡片）+ 代码画的动态内容 + 透明热区。
- 图全部来自 Figma「10月19更新版本 (Copy)」→「02 定制」和「静态补充状态画面」，裁成 402×874 的 webp，放在 `assets/screens/`。另有 3 张模板卡、封面（`book_cover`，从「空白书本」裁掉右下书页白边）、默认封面照片，以及背景素材 `bg_doodle / bg_grass / bg_pink / bg_kraft`（指定的四张图）。
- `assets/space_photos/`：预设空间的照片，从房间电脑「记忆桌面」复制过来（`room/assets/memories/`）。
- **挖洞用 `clip-path: path(evenodd, ...)`，不是 `mask-image`**：这套环境里 `mask-image`/`mask`（长短写法都试过）不生效——`getComputedStyle` 读出来是对的，但画面照常显示整张图，只有 `clip-path` 真的稳定能挖洞。`maskHoles(...rects)` 统一处理，状态栏那条默认总带上；传入的洞如果整个嵌套在另一个更大的洞里会自动丢弃（避免 evenodd 两次相消又变回看得见）。
- **有设计稿、且面板内容仍是画死图的**：素材 5 个分类（分类标签和贴纸图标都是图）、文字面板（字体 / 颜色 / 字号 / 格式的选项文案和图标）、导出面板每行的文案。这几屏只把卡片四周的留白挖空露出背景，面板本身不动。
- **纯代码画的**：纸盘、信封滚轮（和总入口「空间」用同一套素材和关键帧）、模板轮播、合上的相册（4:5 封面 + 镂空照片，镂空照片做了「嵌进封皮」的内凹底 + 内阴影，不再是外部投影的浮起卡片）、编辑页的跨页、总览的页面内容和缩略图条、图片处理面板（背景色整页实心铺满、左右页选中有滑动指示框、已选照片和加号在同一排、一键抠图真的套一个柔边蒙版）、所有顶栏/底部工具栏按钮和导出面板图标（手绘墨线风格，`ICONS` 统一管理）。外观 / 封面 / 背景 / 编辑 / 图片处理页把设计稿里画死的书或面板整块挖掉，换成代码画的内容。
- **外观 / 封面 / 背景拆成两层**：背景层（木纹 / 色块 / 波点 / 水纹 / 用户上传）+ 透明前景图，所以 7 个背景色、6 张素材卡、调色板里的 16 色、上传图片都能让整屏真正变色；封皮颜色只染书本本身（用前景图的透明度做遮罩）。背景设置一旦选定，打开相册之后的每一屏（总览、编辑、素材、图片处理、文字、导出）都跟着同一个背景，不再只在外观/封面/背景三屏生效。
- 热区坐标取自 Figma 图层数据，不是目测。地址后面加 `?debug` 可以看到所有热区。

## 交互和动效（与「空间」部分统一）

- **封面镂空**：镂空图片默认是导入的第一张照片（没有照片就用设计稿里的雪山示例），带白色相纸边和右下错位阴影框。「上方」= 封面上方横图；「右上」= 移到右上角并变成竖图，切换时照片平滑移动变形。镂空位置卡片里补了镂空图片的示意小块（Figma 主稿「05 封面设置」里的画法）。
- **封面 / 背景设置面板**：标题和分组名靠左，和色球左边缘对齐（设计稿新版面板里是居中文本框，看起来缩进太多）。
- **书本过场**：书架 → 合上：书从书架拿下、放大落到地板上，书架虚化淡出；合上 → 打开：封皮绕书脊翻开缩进跨页；打开 → 编辑：点中的那一页放大成编辑页。返回时都是反向动画。
- **编辑页**：一个跨页，当前页在中间，旁边露出另一页的边；点那条边或左右滑，视角滑到另一页（左页 ↔ 右页），跟手、带弹簧。点当前页打开素材面板。页脚有页码。
- **总览**：点左页 / 右页放大进入那一页；左右滑或点箭头翻跨页；页码 = 实际跨页数，加页随之增加。下方缩略图条按顺序画出封面和每个跨页的真实内容（照片、贴纸、文字都跟着对应的页），当前跨页有描边；超出框的两侧淡化，左右划动查看；「+」添加两页空白页。点封面缩略图合上相册。
- **纸盘**：书架点「＋」，和「空间」同一个穿孔纸盘从底部弹起。左右拖动转盘，吸附到「导入」或「创建」，转到正中后轻点进入；往下拖、点空白处或点「‹ 返回书架」把纸盘塞回去。
- **信封滚轮（导入）**：和一级菜单「空间」的信件页同一套——上下拖动 / 甩动带惯性，松手吸附到最近一封，滚过每一封有「嗒」声；「摆正中间那封」可切换。点中间那封或底部黄色「选择」，信封轻轻抬起，带着这个空间的照片进入选模板。点别的信封会把它滚到中间。
- **模板轮播**：卡片跟手拖动，拉过头有阻力，松手按速度弹簧吸附到最近的一套；下面圆点按顺序对应三套模板，跟着拖动连续变长变深，点圆点也能切过去。模板只保留旅行手账 / 乡野胶片 / 花园手记（去掉了极简白）。
- **底部面板**：从下面弹上来，冲过头一点再落稳（640ms，同「空间」表单）。按住面板顶部往下拖，面板跟手走，拖过一段或往下甩就收起，否则弹回原位。点面板上方空白处也能收起。
- **换页**：300ms 淡入（同「空间」）。
- **音效**：用 `JRLX.sound`。tap 轻点、tick 纸盘吸附 / 换模板 / 描边档位、flip 翻页、unfold 纸盘弹起和装订。

## 返回逻辑：一律回上一级，改动随时自动保存，不弹确认框

| 页面 | 返回到 | 返回入口 |
|---|---|---|
| 纸盘 | 书架 | 「‹ 返回书架」、点空白、往下拖 |
| 信封滚轮（导入） | 纸盘 | 左上返回 |
| 选模板 | 书架 | ×、取消、下拉面板 |
| 选照片 | 选模板 | 上一步；× 直接回书架 |
| 合上的相册（外观） | 书架（书飞回书架） | 左上返回 |
| 封面 / 背景设置 | 外观 | 左上返回、完成、下拉面板 |
| 打开的相册（总览） | 合上 | 左上返回、点封面缩略图；「完成」直接放回书架 |
| 编辑某一页 | 总览（这一页缩回跨页） | 左上返回、✓（设计稿没有返回，已补；✓ / 撤销重做右移让位） |
| 素材 / 图片处理 / 文字 | 编辑页 | 同上；也可以下拉面板 |
| 导出 | 打开它的那一页 | 左上返回、完成、下拉面板 |

键盘 Esc 等同于返回。装订中的那 2 秒不响应返回。

## 共享数据与接口

- 只用 `JRLX.ready / onEnter / tabbar / toast / sound / save / load`。
- 信封滚轮用 `state.letters`（总入口里的全部信）；独立预览时用内置的 12 封。
- 预设空间的照片 = `assets/space_photos/` 那 4 张；用户自己新建的空间用 `state.media`。
- 相册照片：装订时一页一张排进内页；封面镂空默认用第一张；图片处理「已选图片」里点哪张就放到当前页；编辑时导入的新照片往后找空页放，不够就加页。
- 只有书架页显示底栏，其余页面和面板都隐藏。
- 存档键 `album_v4`：书架存一组相册（`albums: []`），每本各自的封面、背景、页面都独立存取，不再只有单独一本。上传的照片和图片不进存档（太大），刷新后要重新选；预设空间的照片会保留。

## 已知边界

- 预设的 12 个空间进的都是同一间卧室，所以导入的照片相同。
- 素材分类标签 / 贴纸图标、文字面板的字体 / 颜色 / 字号 / 格式选项、导出面板每行文案，这几处还是设计稿图，不随交互变化。
- 素材搜索、MP4 导出只保留入口提示；一键抠图是给照片套一层柔边蒙版的效果展示，不是真的图像分割。
- 导出 JPG / PDF 用的是预览页的跨页画面，并叠上照片、文字和贴纸；PDF 通过浏览器打印窗口另存。
