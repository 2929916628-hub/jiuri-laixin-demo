# 我的（parts/mine）

负责：底栏「我的」tab —— 个人中心首页 + 5 个设置子页。对应 Figma「03 我的｜个人中心 · 安全/隐私/偏好」。

## 页面清单（7 个 .page，本 iframe 内切换）

| data-page | 页面 | 类型 | 说明 |
|---|---|---|---|
| home | 个人中心 | tab 首页（底栏可见，内容 ≤ y760） | 用户卡 + 账号组 2 行 + 通用组 3 行 |
| account | 账号与安全 | 全屏子页 | 手机号/登录密码/记住登录信息/登录设备管理/注销账号 |
| privacy | 隐私设置 | 全屏子页 | 用户协议/隐私政策入口 |
| perm | 系统权限 | 全屏子页 | 位置/日历/照片/相机/麦克风，点击行翻转授权状态（模拟） |
| notif | 通知设置 | 全屏子页 | 消息通知主开关 + 2 个子开关（主关则子禁用） |
| display | 界面与显示 | 全屏子页 | 深色模式/横屏开关、字体大小三档循环、语言 |
| doc | 协议文档页 | 全屏子页（复用） | 用户协议/隐私政策共用，标题与正文动态替换 |

跳转：首页菜单 → 各子页；子页 `.jrlx-back` 返回；`doc` 固定返回 `privacy`。`JRLX.onEnter` 回首页并收起确认层。

## 操作方法（可演示的交互）

- 首页：点 5 个菜单行进子页；头像为默认猫剪影（media 为空时的兜底）
- 账号与安全：「记住登录信息」开关可切；手机号/登录密码/登录设备管理点击 toast 占位；「注销账号」弹底部确认层（确认仅 toast，不动数据）
- 系统权限：点行切换「已开启/未开启」，toast 反馈
- 通知设置：关「消息通知」后两个子开关变灰禁用
- 界面与显示：点「字体大小」循环 标准→大→特大；深色模式只记录偏好（无深色设计稿）

## 共享数据

- 读：`state.person.name` → 首页用户名称；`state.person.impression` → 首页简介（空则「这个人还没写简介」）
- 存档（`JRLX.save`，自动带 mine 前缀）：`remember_login`、`notif_main`、`notif_float`、`notif_device`、`dark_mode`、`landscape_mode`、`font_size`、`perm_location`、`perm_calendar`、`perm_photos`、`perm_camera`、`perm_mic`
- 用到 JRLX：`ready / onEnter / tabbar / toast / sound / save / load`
