# 旧日来信 · 网页交互 Demo

## 长期在线地址

手机直接打开：<https://2929916628-hub.github.io/jiuri-laixin-demo/>

线上版不依赖这台电脑开机，主流程、房间、声音和新建空间都能体验。新建的空间与上传素材只保存在当前浏览器（IndexedDB），不会跨手机同步；AI 数字分身使用内置示例规则回话。

## 第一次打开

1. 解压后**保持文件夹名 `11_交互Demo_App` 不要改**（地址里要用到它），放在任意位置都行。
2. 电脑上需要装 Python 3（命令行里 `python --version` 能出版本号）。没装的话去 https://www.python.org/downloads/ 下载，安装时勾选「Add Python to PATH」。
3. 启动：
   - **Windows**：双击 `启动预览.cmd`。
   - **Mac**：打开「终端」，把 `启动预览.command` 拖进去，前面加上 `bash ` 再回车（或者右键 → 打开方式 → 终端）。
4. 浏览器会自动打开 `http://127.0.0.1:8125/11_交互Demo_App/`。演示期间那个黑色（终端）窗口不要关，关了服务就停了。

不要直接双击 `index.html` 用 `file://` 打开：字体、房间、AI、保存都会失效。

## 手机上看

电脑端页面左侧有二维码。手机和电脑连同一个 WiFi，或者手机连电脑开的热点，用**手机相机或浏览器**扫（别用微信扫，微信会拦截局域网地址）。
校园网一般会挡住设备之间互访，扫了打不开就改用电脑热点。手机横过来看房间更舒服；看房间里的手机 QQ 时再竖回来。

**不想连热点（手机用流量也能扫）**：在上一级目录建 `_tools` 文件夹，放进 `cloudflared.exe`（https://github.com/cloudflare/cloudflared/releases）或配好 authtoken 的 `cpolar.exe`，启动时会自动开公网链接，二维码换成「公网」那个。链接里带口令，只发给信得过的人；后台和删除接口不对外。电脑要一直开着；开着 VPN 全局模式时 cpolar 和 AI 都会连不上。

## 可以体验的流程

1. 点 App 图标，进入已经装好 12 封信的空间；上下拖动信封，点中间那封翻面。
2. 背面点火漆，拆信进入那间屋子（2009 年的卧室）。第一次进来，每个可点的东西旁边会浮出一句说明。
   - **电脑**：记忆桌面。先只摆几张照片；点一张看完会想起相关的；按住不放，周围浮现更多，还会配一句感官描写和环境音。照片可以拖动。
   - **手机**：TA 当年的 QQ 聊天；如果这封信开了数字分身，TA 会接着回你（每句标来源：A 原话 / C 推测 / D 生成）。
   - **唱片机**：点一下随机放一首歌，再点一下停。
   - 床头柜、吉他、风扇、镜子、吊灯、门各有一段内容。
3. 自己建的空间，翻到背面右下角有「编辑材料」，打开和创建时同一张表单，改完点「保存修改」。
4. 回到信件页，在底部按住「添加空间」往上拉，新建一个空间：选「自己」或「他人」→ 填表 → 选空间场景（卧室 / 教室 / 小区游乐场，目前只有卧室能进去）→ 构建。
5. 选「他人」时可以打开「数字分身」：上传聊天截图或录屏（不传就用内置示例录屏），会抽帧、识别聊天、总结说话方式，之后在房间的手机里和 TA 聊。

## 数字分身和照片分析用的 AI（可选）

线上版会用手机浏览器内置的本地视觉模型识别上传照片，生成一段感官描写并自动加入环境声；模型约 18MB，第一次会稍慢，之后会使用浏览器缓存。数字分身仍会用示例人物「阿哲」和内置规则回话。

想用真 AI：双击 `配置AI.cmd`（Mac 在终端运行 `python3 _ai_setup.py`），在弹出的小窗口里粘贴**你自己的** DeepSeek key（https://platform.deepseek.com）。
key 只存在你电脑用户目录的 `.jrlx_ai.json`，不在这个文件夹里，打包转发也不会带上。

## 新建的空间存在哪

新建的空间（上传的照片视频、信封、数字分身）会保存到**上一级目录**的 `_demo_data` 文件夹，刷新、换手机扫码都还在。
后台管理：电脑端左侧「数据后台」，或打开 `http://127.0.0.1:8125/11_交互Demo_App/admin.html`，可以移到回收站、恢复、彻底删除。

## 目录

- `index.html`、`js/`、`css/`、`assets/`：总入口（启动页、信件、新建空间、表单）。
- `room/`：房间（全景、电脑记忆桌面、手机 QQ、唱片机）。
- `shared/`：公共样式、页面通信 `bridge.js`、数字分身 `twin.js`。
- `parts/custom/`「定制」、`parts/mine/`「我的」：组员各自负责的部分，规则见 `协作约定.md` 和 `给组员的提示词.md`。
- `_serve.py`：本地服务（预览、手机扫码、AI 转发、保存数据）。

## 已知边界

- 「定制」「我的」还是待制作的模板页。
- 只有卧室这一个房间；选教室 / 游乐场进去的还是卧室。
- 手机浏览器对声音限制严：进房间后先随便点一下屏幕，再点唱片机或照片，才有声音。
- 教室、游乐场两张场景图来自网络，唱片机的两首歌是商业歌曲：**只用于课堂演示，对外发布前要换成自有或有授权的素材**。环境音来自 Mixkit（免费授权，见 `room/assets/ambience/LICENSE_来源.txt`）。
